# BUG-006: 시나리오 등록 시 원본 문서 덮어쓰기

## 상태: 수정완료 (T12, 2026-09-23)

## 증상
이미 있는 시나리오 폴더 이름으로 `POST /api/scenarios`를 호출하면 `world.md`, `scenario.md`, `characters/protagonist.md`가 템플릿 내용으로 덮어써진다. 템플릿이 없으면 `# world.md` 한 줄만 남는다.

## 원인
`ScenarioService.copyTemplate`이 `Files.copy(..., StandardCopyOption.REPLACE_EXISTING)`로 복사한다.

## 발견
2026-09-23, T11 수동 확인을 준비하다 발견. 스크래치 복사본이라 실제 피해는 없었다.

## 수정 (T12)
- `copyTemplate`: 대상 파일이 이미 있으면 복사하지 않는다. 템플릿이 없을 때의 한 줄짜리 파일도 없을 때만 만든다. 쓰기는 `REPLACE_EXISTING` 없이 `Files.copy`/`CREATE_NEW`로 해서 확인과 쓰기 사이에 생긴 파일도 덮어쓰지 않는다.
- 같은 문제가 있던 `chat/chat_latest.md` 초기화(`writeString`으로 매번 덮어씀)도 없을 때만 쓴다. 옛 폴더의 대화 원문이 지워질 수 있었다.
- 회귀 테스트(`ScenarioServiceTest`): 기존 폴더 등록 시 `world.md`, `scenario.md`, `characters/protagonist.md`, `chat/chat_latest.md` 보존, 없던 파일만 템플릿으로 채움, 템플릿이 없을 때도 보존. 수정 전 코드에서는 두 테스트가 실패하는 것을 확인했다.
