# BUG-006: 시나리오 등록 시 원본 문서 덮어쓰기

## 상태: 수정 예정 (T12)

## 증상
이미 있는 시나리오 폴더 이름으로 `POST /api/scenarios`를 호출하면 `world.md`, `scenario.md`, `characters/protagonist.md`가 템플릿 내용으로 덮어써진다. 템플릿이 없으면 `# world.md` 한 줄만 남는다.

## 원인
`ScenarioService.copyTemplate`이 `Files.copy(..., StandardCopyOption.REPLACE_EXISTING)`로 복사한다.

## 발견
2026-09-23, T11 수동 확인을 준비하다 발견. 스크래치 복사본이라 실제 피해는 없었다.

## 수정 계획
- 대상 파일이 이미 있으면 복사하지 않는다(기존 폴더 등록 시 원본 보존)
- 회귀 테스트 추가
