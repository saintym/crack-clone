# BUG-002: 채팅 히스토리 파싱 오류

## 상태: 수정완료

## 증상
채팅 화면 진입 시 기존 대화 내용이 표시되지 않음

## 원인
- 백엔드 `/chat/history` API 응답: `{ content: "# 최근 대화\n\n## USER\n..." }`
- 프론트엔드에서 `data`를 바로 `string`으로 취급하여 `parseHistory(data)` 호출
- 실제로는 `data.content`에 문자열이 들어있음

## 수정 내용
- **파일**: `crack-frontend/src/pages/ChatPage.tsx`
- `parseHistory(data)` → `parseHistory(data.content)`
- **파일**: `crack-frontend/src/api/chat.ts`
- 반환 타입을 `string` → `{ content: string }`으로 수정

## 근본 원인
백엔드 `ChatController.getHistory()`가 `Map<String, String>`을 반환하는데, 프론트에서 plain string으로 가정
