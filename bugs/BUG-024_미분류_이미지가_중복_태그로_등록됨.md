# BUG-024: 가져오기가 미분류 이미지를 같은 태그 이름으로 중복 등록

## 상태: 수정 예정 (T29)
## 심각도: 낮음

## 증상
URL 가져오기(T28)로 만든 `images.md`에 인물과 매칭되지 않은 이미지가 `- 태그를_정하세요: URL` 형태로 **여러 줄 같은 이름으로** 들어간다. 태그가 중복이면 첫 항목만 인식되고 나머지는 무시된다(카탈로그 파서 규칙).

## 재현
`https://jangsue.uk/MG/web.html`과 `https://jangsue.uk/HT/FWeb.html`을 가져오면 각각 3줄이 생긴다.

## 원인
T28 명세에는 "인물과 매칭 안 되는 이미지는 장면 태그 후보로 **주석 처리**해 둔다"고 되어 있는데, 구현이 실제 항목으로 등록했다.

## 수정 방향
미분류 이미지는 주석(`<!-- 미분류 이미지 N: URL -->`)으로 남긴다. 사용자가 주석을 풀고 태그 이름을 정하면 쓰인다. 이미 만들어진 두 시나리오의 파일은 오케스트레이터가 수동으로 정리했다(2026-09-26).
