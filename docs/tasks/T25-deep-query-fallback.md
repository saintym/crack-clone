## 목표
"아까 뭐라고 했지", "그때 약속" 같이 **과거를 참조하는 턴**인데 키워드 검색이 아무것도 찾지 못하면, 세계관 관리자를 **1회만** 호출해 필요한 정보를 받아 그 턴에 넣는다. 매 턴 질의는 하지 않는다(D8, D23).

## 범위
- 신규 `crack-backend/src/main/kotlin/com/crack/memory/world/DeepQuery*.kt`
- `chat/flow/**`(응답 생성 전 1회 호출 지점), `prompt/**`(주입 슬롯)
- `docs/DESIGN.md`(§6 또는 §7에 절 추가), 관련 테스트

## 구현 내용
1. **호출 조건(둘 다 만족해야 한다)**
   - 이번 입력이나 최근 2턴에 **과거 참조 신호**가 있다: 패턴 목록(`아까`, `그때`, `예전`, `전에`, `약속`, `말했`, `기억하`… 설정으로 확장 가능)
   - `scenario_index.md`와 키워드북 검색 결과가 **모두 비어 있다**
   - 추가 안전장치: 스토리당 최근 N턴 내 1회(기본 5턴), 설정으로 끌 수 있게(`crack.prompt.deep-query.enabled`)
2. **질의**: 관리자에게 `연대기 + 다이제스트 + 색인 제목 목록 + 최근 대화 몇 줄`을 주고 "이번 턴에 필요한 과거 정보만 200자 이내로" 요청한다. purpose는 `UTILITY`(가벼운 등급).
3. **주입**: 결과를 `[과거 기록]` 블록으로 프롬프트에 넣는다. 위치는 KEYWORDS 슬롯 뒤.
4. **실패·타임아웃**: 그냥 건너뛴다(응답 생성은 계속). 지연이 커지면 안 되므로 타임아웃 기본 15초.
5. **관측**: 호출 여부와 이유를 INFO 로그와 `prompt-preview` 응답에 남긴다.
