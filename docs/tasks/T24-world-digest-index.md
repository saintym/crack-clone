## 구현 내용
1. **파일 두 개를 스토리 폴더에 만든다.**
   - `digest.md` — 항상 프롬프트에 들어간다. 예산 `crack.memory.budget.digest`(기본 3000자). 세력 관계, 세계 규칙, 진행 중인 큰 줄기
   - `scenario_index.md` — 주제 단위 조각. 형식은 키워드북(`keywords.md`)과 **같은 구조**로 두어 `KeywordBookParser`·`KeywordMatcher`(T06)를 재사용한다
     ```markdown
     ## 천마신교 계보
     키워드: 천마신교, 마교, 신교, 교주
     (원문에서 뽑은 내용)
     ```
2. **빌드는 1회**(D22). 스토리 생성 직후(비동기) 또는 첫 기록 때 `scenario.md` + `world.md`를 읽어 두 파일을 만든다. 원문이 길면 나눠 호출해도 되지만 **호출 수를 로그에 남긴다**. 빌드 실패 시 원문 주입으로 폴백하고 다음 기록 때 다시 시도한다.
3. **매 턴 주입**(D23)
   - SCENARIO 슬롯: `digest.md` + 연대기(기존) — **원문 `scenario.md`는 넣지 않는다**
   - 새 기여자: `scenario_index.md`를 `KeywordMatcher`로 검색해 매칭된 조각만 넣는다. 동시 주입 수는 `crack.prompt.scenario-chunk-max-active`(기본 3)
   - 다이제스트가 없으면(빌드 전·실패) 기존처럼 원문을 넣는다
4. **갱신**: 연대기 압축이 도는 기록에서만 다이제스트를 갱신한다(D22). 색인은 스토리의 `scenario.md`가 바뀌었을 때만 다시 만든다(수정 시각 비교).
5. **원문 범위를 글자 예산으로**(D25)
   - `crack.prompt.raw-budget-chars`(기본 6000), `raw-budget-max-chars`(10000), `raw-min-turns`(2)를 새로 둔다. 최근 턴부터 예산을 채울 때까지 담고, 예산을 넘겨도 최소 2턴은 넣는다
   - 턴 하나를 쪼개지 않는다(유저+응답은 같은 턴이므로 함께 넣거나 함께 뺀다)
   - 기존 `max-raw-turns`는 안전 상한으로만 남기거나(예: 30) 제거한다. `overlap-turns`가 의미를 잃으면 정리한다
   - 실제로 몇 턴이 들어갔는지 `prompt-preview`와 INFO 로그에 남긴다
6. **롤플레이 마스터 역할**(D26): BASE 규칙에 역할 정의를 넣는다 — 주인공 주변의 시간·공간·인물을 고려해 사건을 진행시킨다, 정보는 다이제스트·연대기·인물 문서·최근 대화에서 얻는다, 없는 설정을 만들지 말고 모르면 장면 안에서 자연스럽게 비워 둔다.
7. **활성 인물 집합 고정**(D30): 활성 인물을 매 턴 다시 고르지 말고 **기억 기록 회차 동안 고정**한다.
   - `state.json`(또는 별도 파일)에 이번 회차의 활성 인물 목록을 저장한다
   - 새 인물 이름이 최근 대화에 나오면 집합에 **추가**한다(제거는 기록 시점에만)
   - 기억 기록이 끝나면 동행 목록 기준으로 다시 계산한다
   - 근거: 캐시는 접두사 일치라서 인물 섹션이 매 턴 바뀌면 비용이 16배로 튄다(로드맵 §2.4 실측)
8. **캐시 친화 순서**(D28): 슬롯 순서를 안정→변동으로 맞춘다(BASE → WORLD → SCENARIO(다이제스트) → PROTAGONIST → CHARACTERS(활성 인물) → KEYWORDS(조각) → USER_NOTE → IMAGES → 대화 → BOTTOM). 지금 순서에서 바뀌는 부분이 있으면 근거를 작업 로그에 적는다. API 프로바이더 경로에는 다이제스트 끝에 `cache_control` 지점을 둘 수 있게 준비하되, 실제 적용은 별도 작업으로 남겨도 된다.
9. **측정**: 마도생존기 실데이터로 `prompt-preview` 기준 변경 전후 섹션 크기를 비교해 작업 로그와 `Plan-roadmap.md` §2.4에 기록한다. 목표는 scenario 계열 17,698자 → 3,000자 + 조각 최대 약 2,000자.
